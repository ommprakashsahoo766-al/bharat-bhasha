# 🇮🇳 Bharat Bhasha

### Learn Indian Languages Through Simple Practice

**Bharat Bhasha** is a Python-based language learning project designed to help users learn basic words, greetings, daily phrases, and numbers from different Indian languages.

The goal of the project is to make learning Indian languages simple, interactive, and beginner-friendly.

---

## 🌐 Languages Available

Currently, Bharat Bhasha supports:

* 🇬🇧 English
* 🇮🇳 Hindi
* 🟠 Odia
* 🟢 Bengali
* 🟡 Punjabi
* 🔵 Telugu
* 🔴 Tamil
* 🟣 Marathi
* 🟤 Gujarati
* 🟢 Assamese
* 🟠 Bhojpuri
* 🔵 Haryanvi

```text
Bharat-Bhasha/
│

├── quiz.py
├── progress.py
└── README.md
```

### File Description

**app.py**
Main application that handles the menu, language selection, learning topics, quiz, and progress tracking.

**languages.py**
Contains the learning content for all supported languages.

**quiz.py**
Contains quiz questions, options, answers, and the quiz scoring system.

**progress.py**
Tracks completed learning topics and the user's best quiz score during the program session.

**README.md**
Project documentation.

---

## ⚙️ How It Works

1. Start the application.
2. Select an Indian language.
3. Choose a learning topic.
4. Learn words, phrases, greetings, or numbers.
5. Take the practice quiz.
6. View your learning progress.
7. Continue learning or switch to another language.
